Always there. Never in the way.

  • Tray

    Sits quietly until you need it.

  • Hotkey

    One global key, over any app.

  • Heads-up card

    Always on top, short, with its sources.

  • Both sides

    Hears your mic and the call.

Nothing leaves your machine

Every part of the pipeline runs on this computer.

  • Speech

    whisper.cpp in a local container.

  • Model

    A 4B model, served by Ollama on your GPU.

  • Memory

    PostgreSQL on this computer.

  • Network

    No transcript is sent anywhere.

Install

  1. Get the code

    git clone https://github.com/aakashksen/ContextLens-Neo

  2. Pull the models

    ollama pull qwen3.5:4b-q4_K_M
ollama pull nomic-embed-text

  3. Start speech, memory and the backend

    py -3.12 tools/run_everything.py

  4. Build the app

    cd clients/desktop
npm install
npm run dist
