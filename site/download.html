Get ContextLens Neo

Two ways to use it. Both run on your own computer, so nothing you say leaves it.

Windows Desktop app A tray app with one hotkey. The card floats over any call. Desktop setup Unity, XR Smart glasses The card appears in front of you. Tap to ask. Glasses setup

Want to see it first? Watch it work in your browser. Nothing to install.

Desktop app · Windows

Set up the desktop app

About 15 minutes the first time, most of it spent downloading models.

  1. Get the code

    git clone https://github.com/aakashksen/ContextLens-Neo
cd ContextLens-Neo

  2. Pull the models

    ollama pull qwen3.5:4b-q4_K_M
ollama pull nomic-embed-text

  3. Start speech, memory and the backend

    py -3.12 tools/run_everything.py

  4. Build and install the app

    cd clients/desktop
npm install
npm run dist

    The installer lands in clients/desktop/dist. Run it, then press the hotkey in any call.

You need

Windows 10 or 11
The app is a tray app with a global hotkey.
Ollama
Runs the 4B model and embeddings.
Docker
Runs speech and PostgreSQL.
Node.js and Python 3.12
Build the app and run the backend.
A GPU with 8 GB
For the local model.

Smart glasses · Unity

Set up the glasses client

The glasses show the card. Your computer does the work, with the same backend as the desktop app.

  1. Start the backend

    Follow steps 1 to 3 of the desktop setup. To try the client on its own, the sample server answers with ready-made cards:

    python tools/fake_server.py

  2. Open the project

    In Unity Hub, open clients/unity with Unity 6000.3.3f1.

  3. Play or build

    Press Play to try it in the editor. For a headset, add its XR plug-in, set the client’s server address to your computer, and build.

  4. Ask

    Tap, or press the primary controller button. The card appears in front of you.

You need

Unity 6000.3.3f1
The project brings the XR Interaction Toolkit with it.
A headset or glasses
Any XR device Unity supports. The editor works without one.
The same network
The client talks to your computer over one WebSocket.
